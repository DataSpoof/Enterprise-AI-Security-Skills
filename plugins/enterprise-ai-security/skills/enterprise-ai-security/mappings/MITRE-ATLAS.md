# MITRE ATLAS mapping notes

Use MITRE ATLAS to describe relevant adversary tactics and techniques for AI-enabled systems. Begin with the advanced threat catalog and the testing matrix, then trace each selected technique to the actual system boundary, evidence, mitigation, and safe validation case.

Do not infer ATLAS technique identifiers from topic similarity. Confirm current identifiers and descriptions in the [ATLAS matrix](https://atlas.mitre.org/) and record the matrix version or access date in formal deliverables.
