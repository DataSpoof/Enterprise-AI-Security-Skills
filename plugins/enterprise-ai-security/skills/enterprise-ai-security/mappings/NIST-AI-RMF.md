# NIST AI RMF mapping notes

Use the NIST AI Risk Management Framework to organize AI risk governance and lifecycle work, and the NIST Generative AI Profile (AI 600-1) for generative-AI considerations. Start with the governance and development reference, then use the domain references to identify technical risks and evidence.

The supplied baseline provides a practical security control library, not a direct mapping to NIST functions or categories. Record any formal correspondence only after checking the current NIST publication and documenting its rationale. See [NIST AI RMF resources](https://www.nist.gov/itl/ai-risk-management-framework) and the [Generative AI Profile](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-generative-artificial-intelligence).
