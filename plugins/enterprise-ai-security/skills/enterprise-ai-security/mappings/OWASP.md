# OWASP mapping notes

Use the current OWASP GenAI Security Project publications as a threat and control reference. The supplied baseline names the OWASP GenAI LLM Top 10, Top 10 for Agentic Applications, and Agent Control Standard. Its relevant material is organized in:

- LLM security and prompt protection
- RAG, vector databases, and document intelligence
- Agentic AI and tool security
- Governance, development, and testing
- Advanced threat catalog and security testing matrix

This is a topic-level working crosswalk, not an official item-by-item mapping. Confirm publication editions and exact identifiers at [OWASP GenAI Security Project](https://genai.owasp.org/) before recording a formal framework control.
