# Skill package instructions

- SKILL.md is the portable entry point; load only the modules relevant to the user's task.
- Preserve the supplied baseline in enterprise-ai-security-baseline.md and preserve its control IDs in deliverables.
- Use framework mapping notes as orientation, not as proof of direct control equivalence or certification.
- Default to passive analysis and isolated test plans. Active testing requires explicit written authorization and a bounded scope.
- Pair each material risk with remediation and verification or detection evidence.
- Do not declare unknown controls effective. Mark status as implemented, tested, planned, not applicable, or unknown as evidence warrants.
- Keep the skill's metadata, index, and package versions synchronized.
